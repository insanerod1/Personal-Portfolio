# Personal Portfolio Website

A responsive personal portfolio website built with HTML, Sass, Bootstrap, and JavaScript. The site showcases my projects, skills, experience, and contact information through a custom design with gradients, responsive layouts, technology badges, and interactive project modals.

Projects are stored in a JSON file and loaded dynamically with JavaScript, making it easy to add new projects without rewriting the HTML structure.

## Technologies

- HTML
- Sass/SCSS
- Bootstrap
- JavaScript
- JSON

## Features

- Responsive portfolio layout
- Custom Sass color system and gradients
- Dynamically generated project cards
- Technology badges for each project
- Bootstrap modal for detailed project information
- Responsive navigation bar
- Project images and links
